COMPILERLAB: WHAT YOU NEED TO DO BY HAND
=========================================

THIS IS AN UNFINISHED SNAPSHOT (4 November 2026). Read section 6 first.
The new code compiles and builds, but none of it has ever been run.


1. REQUIRED DOWNLOADS
---------------------
Node.js 22 LTS (version 22.22.2 or newer, but below 23)
  Windows:      winget install --id CoreyButler.NVMforWindows -e
                nvm install 22
                nvm use 22
  macOS/Linux:  curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
                nvm install        (reads .nvmrc in the project folder)
                nvm use
  npm comes with Node. Newer Node versions get a warning. Older ones cannot run.

A browser: Chrome, Edge or Firefox.

Windows only: unzip to a short path such as C:\compilerlab. Some paths are long, and a deep
folder can cause "Filename too long" errors.


2. START THE APP
----------------
In the compilerlab folder:

  npm run setup     Installs everything and checks your computer. Needs internet the first time.
  npm start         Starts the app and opens http://127.0.0.1:5173

Other commands:

  npm run doctor    Checks Node, SQLite, the lab tools and the Gemini key, with exact fixes
  npm run build     Then: npm run start:prod    Runs the built app on one port, http://127.0.0.1:4317
  npm run backup    Backs up your data
  npm run reset     Deletes your data but keeps backups


3. KEYS AND SETTINGS (.env file)
--------------------------------
The .env file is included, with every value blank. A blank value uses the default below.
Only GEMINI_API_KEY needs filling in, and only if you want AI features.

  GEMINI_API_KEY              Blank by default. Get a key at https://aistudio.google.com/apikey
                              Without it, AI features show an offline state and everything
                              else still works. The key stays on the local server.
  GEMINI_MODEL                Default: gemini-3.5-flash-lite
                              Not confirmed: no real AI call has ever been made. If you get a
                              model error, pick a current one from
                              https://aistudio.google.com/docs/models
  GEMINI_REQUESTS_PER_MINUTE  Default: 10. A cautious guess. Set it to your real limit.
  GEMINI_REQUESTS_PER_DAY     Default: 250. A cautious guess. Set it to your real limit.
  PORT                        Default: 4317. The local server.
  WEB_PORT                    Default: 5173. The web page during development.
  LOG_LEVEL                   Default: warn.

  Optional, and commented out in the file:
  COMPILERLAB_DATA_DIR        Default: ./data
  SQLITE_DRIVER               Set to node:sqlite if better-sqlite3 will not load.

Restart the app after changing .env. Never commit or share a .env holding a real key.


4. OPTIONAL DOWNLOADS: THE REAL LAB TOOLS (flex, bison, gcc, g++, make)
-----------------------------------------------------------------------
Without them, Lex programs run in a built-in engine labeled "Simulated", and C and C++ programs
show install commands instead.

  Windows, MSYS2:  winget install --id MSYS2.MSYS2 -e
                   In the "MSYS2 UCRT64" terminal:
                   pacman -S --needed flex bison make mingw-w64-ucrt-x86_64-gcc
                   Add C:\msys64\ucrt64\bin and C:\msys64\usr\bin to PATH, or set the
                   tool paths in the app's Settings page.
  Windows, WSL2:   wsl --install -d Ubuntu
                   Then run all of CompilerLab inside Ubuntu, using the Ubuntu line below.
  macOS:           xcode-select --install
                   brew install flex bison
                   Add to ~/.zshrc:
                   export PATH="$(brew --prefix)/opt/bison/bin:$(brew --prefix)/opt/flex/bin:$PATH"
  Ubuntu:          sudo apt update && sudo apt install -y flex bison gcc g++ make

Then run: npm run doctor


5. TESTING (ALL LEFT TO YOU)
----------------------------
  npm run check                     Lint, type checks, unit tests and build
  npx vitest run real-tools         Runs exercise solutions through real flex and gcc.
                                    These skip themselves if the tools are missing.
  npx playwright install chromium   Once, for browser tests
  npm run build                     Browser tests use the built app, so build first
  npm run test:e2e                  Browser tests

Expect failures on this snapshot. Nothing above has been run since the new code was added, so
formatting checks and older tests may fail. New code since Milestone 3 has no tests at all, even
though the spec requires engine tests against textbook answers. Points to check against the book
are listed in docs/CONTENT_REVIEW.md.
